## 쉬운 설명

처음 계획에서는 학습 중 이상이 감지되면 자동으로 이메일을 받도록 했으나, 실제로는 **로컬 텍스트 파일**(`logs/alerts/`)에만 기록하기로 결정했습니다.

이유:
- 로컬 개발 환경에서 이메일 설정/유지보수의 복잡성 회피
- 파일 기반 알림으로 충분 (개발자가 필요할 때 파일을 확인)
- 향후 필요하면 파일 감시 도구(예: fswatch)와 연동 가능

## 필요한 입력

- **문제 정의서 (problem.md) 초안**: 원래 "알림 채널: 이메일 + 텍스트 파일"이었으나, T2-4에서 이메일을 취소하기로 결정
- **T2-3**: 텍스트 파일 알림 설정 완료
- **사용자 판단**: 이메일 불필요 판단
