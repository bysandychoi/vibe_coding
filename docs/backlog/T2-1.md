## 목적

정상적인 REINFORCE 학습 5회의 gradient norm 데이터를 수집한 후, 그 데이터로부터 "gradient explosion"을 판정할 고정 임계치를 산출하는 방식을 결정한다.

**결정 내용 (이미 확정)**: 통계량 = **평균 + k×표준편차** (baseline 5회의 모든 epoch에서 수집한 gradient_norm 값을 풀링해 산출), **k=5** (초기값, baseline 관찰 후 오탐/누락 여부를 보고 조정 가능)

## 쉬운 설명

Gradient norm은 신경망의 모든 가중치 업데이트 크기를 한 개의 스칼라 값으로 나타낸 것이다. 정상 학습에서는 대략 비슷한 범위에서 움직이지만, gradient explosion이 발생하면 갑자기 수십 배 이상으로 급증한다.

현재 문제 정의(problem.md)에서 정한 전략:
- "정상 학습 5회를 baseline으로 관찰한 뒤 고정 임계치 설정"
- 즉, 정상인 경우의 gradient norm을 여러 번 기록해 그 패턴을 분석하고, "이 수치 이상은 이상이다"라는 경계선을 정하겠다는 의도

**이번 결정의 핵심**:
- "평균 ± 표준편차 방식"을 택했다 → 통계적으로 자연스럽고, 정상 분포를 가정할 수 있음
- k=5를 초기값으로 사용 → baseline 5회 전체 epoch의 gradient_norm 값을 풀링해 `mean + 5*std`를 임계치로 설정

- k 초기값: 5

다만, 아래는 **구현 단계(T2-7 이후)에서 확인이 필요한 사항**입니다:

1. **baseline 5회의 구체적 정의**: T2-2의 자동 필터 3가지를 통과한 후보 중 사람이 최종 선택한 5회를 의미하는가? 또한, 각 run마다 로그 파일명/형식은 어떻게 할지(T2-3 결정 후 확인)?
