## 목적

T2-1에서 gradient explosion 임계치를 산출하기 위해 필요한 "정상 학습 run 5회"를 어떻게 정의하고 판별할지 결정한다.

**결정 내용 (이미 확정)**: **최소 자동 필터 + 사람 최종 승인** 방식
- 자동 필터 3가지로 명확한 이상 사례 제외
- 필터 통과한 후보들 중 사람이 최종 5회 확정

## 쉬운 설명

gradient explosion의 임계치를 정하려면 "정상적인 상황에서 gradient norm이 어느 정도인가"를 알아야 한다. 그래서 정상 학습을 5번 돌려서 그 데이터를 수집하려고 한다.

하지만 "정상"의 정의가 애매하다:
- loss/reward가 어떤 방향이어야 정상인가?
- loss가 조금만 내려가도 정상인가?
- 과거의 명백한 이상 사례(reward 전부 0 등)는 어떻게 제외할 것인가?

이 결정은 "정상 run"을 어떤 기준으로 수집할지 명확히 하고, 필터링 절차를 정하는 것이다.

## 필요한 입력

- **problem.md §3**: "reward가 오르지 않고 정체된 상태를 최소 50 epoch까지는 지켜보는 편" (기존 관행)
- **problem.md §3 과거 사례**: (A) batch 내 reward 전부 0, (B) gradient explosion
- **T2-1**: gradient explosion 임계치 산출을 위해 baseline 필요
- **실행 환경**: REINFORCE 스케줄러, 환경 고정, 설정 epoch 수 (기본값 50 이상으로 추정)

## 결과물

**이미 확정된 결정 내용**:

```
"정상 run" 5회 판별 기준:

방식: 최소 자동 필터 + 사람 최종 승인

자동 필터 (다음 3가지 모두 만족하는 run만 후보):
  1. NaN/Inf loss·gradient 없이 완주
     → 수치적 이상이 없는 run만 대상
  2. 중단 없이 설정된 epoch까지 정상 종료
     → 학습이 끝까지 진행된 run만 대상
  3. reward가 batch 전체에서 0인 epoch 없음
     → 과거 사례 A (batch 내 reward 전부 0) 배제

사람 최종 승인:
  필터 통과한 후보 run들 중에서 개발자가 직접 로그를 보고 
  "이 5개는 정상이다"고 판단해 최종 선정

확인 체크리스트 (필터 통과 후):
  [ ] loss 급격한 폭증 없음
  [ ] entropy 지나친 붕괴 없음
  [ ] gradient norm 큰 변동 없음 (폭발적 증가 제외)
  → 모두 만족하면 최종 선정
```
